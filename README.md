# 프리코스 2주차 - 자동차 경주

## 기능 요구사항
- 쉼표로 구분된 자동차 n대를 입력받는다. 이름은 5자 이하다.
- 사용자는 전진 시도 횟수를 입력할 수 있다.
- 매 전진 회차에 자동차마다 0~9사이의 난수를 구하고, 4이상이면 전진한다.
- 매 회차가 끝나고 나면 결과를 자동차 이름과 함께 출력한다.
- 모든 회차가 끝나면 최종 우승자를 출력한다. 중복 순위도 가능하다.
- 우승자가 여러명이면 쉼표로 구분한다.
- 사용자가 잘못된 값을 입력하면 IllegalArgumentException 을 발생시키고 종료한다.


## 주의사항
- 자동차 이름은 빈값, 띄어쓰기 일 수 없다.
- 자동차의 개수 제한은 없다.
- 전진 시도 횟수는 반드시 양수만 가능하다.
- 들여쓰기는 깊이 2까지만 허용된다.
- 3항 연산자를 쓰지 않는다.
- 난수는 camp.nextstep.edu.missionutils.Randoms 의 pickNumberInRange() 함수로 구한다.


## 구현 기능 목록
### 입력
- 자동차 이름 입력받기
- 시도 횟수(회차) 입력받기

### 진행
- 자동차 이름 쉼표 기준으로 분리하기
- 입력된 자동차 이름 검증(빈값, 띄어쓰기, 5자 이하)
- 입력된 시도 횟수 검증 (양수)
- 자동차들 저장하기
- 각 자동차들에 대해 난수 구하기
- 각 자동차들 전진 여부 구하기
- 1회차가 끝난 이후 각 자동차들의 위치 결과 저장하기
- n회차만큼 반복하기
- 최종 우승자 판단하기

## 출력
- 1회차가 끝난 이후 결과 출력하기
- 우승자 출력하기. 다수일 경우는 쉼표로 구분
